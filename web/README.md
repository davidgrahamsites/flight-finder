# FlightFinder Web

Browser version of FlightFinder with:

- 3-route concurrent comparison
- one-way/round-trip controls
- bag/passenger/cabin/nonstop/max-stop options
- provider type mix (airline, metasearch, OTA, China portals)
- China-accessible mode with non-AI learning from probe outcomes
- direct provider deep links for booking handoff

## Local Development (localhost)

```bash
cd web
npm install
npm run dev
```

- UI: `http://localhost:5173`
- API: `http://localhost:8787`

## Production Build + Local Smoke Run

```bash
cd web
npm run build
NODE_ENV=production npm run start
```

Open `http://localhost:8787`.

## API Endpoints

- `GET /api/health`
- `GET /api/providers`
- `GET /api/china/snapshots`
- `POST /api/china/probe`
- `POST /api/search`

## Monetization-Ready Affiliate Params

Supported providers can inject affiliate params through environment variables (`.env.example`).

Example:

```bash
export AFFILIATE_TRIP_ALLIANCE_ID=12345
export AFFILIATE_TRIP_SID=flightfinder
```

Then links generated by the API automatically include those parameters.
